# 万灵 (WanLing)

诛仙世界辅助工具 · 绿色便携版。

## 下载

请到 [Releases](https://github.com/MyMoonCat/WanLing/releases) 下载最新 `WanLing.exe`。

## 自动更新

本仓库的 Release 是客户端自动更新源：

- 每个版本上传：`WanLing.exe`（或 `WanLing-vX.Y.Z.exe`）
- 附带 `latest.json`（version / url / sha256）

用户数据保存在 `%LocalAppData%\万灵`，更新 exe 不会清空配置。

## 仓库用途

公开 Release 托管与版本清单；源码可另存私有库维护。
